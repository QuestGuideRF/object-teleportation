# 🌀 Object Teleportation

Интерактивная симуляция телепортации мягких тел через порталы с использованием WebAssembly и Three.js.

## 📖 Описание проекта

**Object Teleportation** — это веб-приложение для симуляции физики мягких тел (softbody), которые проходят через порталы. Проект демонстрирует сложные физические взаимодействия с использованием:

- **WebAssembly (Rust)** — высокопроизводительные вычисления физики
- **Three.js** — 3D-визуализация и рендеринг
- **Интерактивный GUI** — настройка параметров в реальном времени

### Основные возможности

- ✨ **Симуляция мягких тел** — реалистичная физика с пружинами и демпфированием
- 🔮 **Порталы** — различные типы порталов (отражение, перспектива, обычные)
- 🎨 **Интерактивная визуализация** — настройка цветов, размеров и параметров
- ⚡ **Высокая производительность** — оптимизированные вычисления на WebAssembly
- 🎮 **Множество сцен** — предустановленные сценарии для экспериментов

## 🚀 Установка

### Требования

- [Rust](https://rustup.rs/) (последняя версия)
- Веб-сервер для локального запуска

### Шаги установки

1. **Установите Rust** (если еще не установлен):
   ```bash
   # Перейдите на https://rustup.rs/ и следуйте инструкциям
   ```

2. **Установите необходимые инструменты**:
   ```bash
   # Установка wasm-pack для сборки WebAssembly
   cargo install wasm-pack

   # Установка miniserve для локального веб-сервера
   cargo install miniserve
   ```

3. **Соберите WebAssembly модуль**:
   ```bash
   cd wasm
   wasm-pack build --target web
   ```

4. **Запустите локальный сервер**:
   ```bash
   # Из корневой директории проекта
   miniserve .
   ```

5. **Откройте в браузере**:
   ```
   http://localhost:8080/index.html
   ```

## 💻 Использование

### Запуск симуляции

1. Откройте приложение в браузере
2. В правом верхнем углу найдите панель управления (GUI)
3. Нажмите **"Run simulation"** для запуска симуляции
4. Используйте мышь для перемещения камеры (перетаскивание)

### Настройка параметров

#### Физические параметры
- **Spring force** — сила пружин между частицами
- **Spring damping** — демпфирование пружин
- **Speed damping** — общее демпфирование скорости
- **Δt** — шаг времени симуляции
- **Iters** — количество итераций на кадр

#### Параметры сцены
- **Grid size** — размер сетки частиц
- **Scale** — масштаб объекта
- **Offset.x/y** — смещение объекта
- **Speed.x/y** — начальная скорость объекта
- **Portal type** — тип портала (0-2)
- **Portal1/2** — позиция и угол порталов

#### Визуальные настройки
- **Particle Size** — размер частиц
- **Particle Color** — цвет частиц и линий
- **Line2/4 Color** — цвета специальных линий
- **Circle1/2 Color** — цвета порталов
- **Show debug grid** — показать сетку координат

### Предустановленные сцены

В выпадающем списке **"Scene"** доступны различные предустановленные сценарии:

- **default** — стандартная сцена
- **rigid** — более жесткое тело
- **more rigid** — очень жесткое тело
- **big** — увеличенный объект
- **even bigger** — еще больше
- **refraction** — эффект преломления
- **reflection** — эффект отражения
- **small** — маленький объект
- **no springs** — без пружин
- **kiss** — сцена с близкими порталами
- **monoportal** — один портал
- **perspective portal** — перспективный портал

## 🏗️ Архитектура проекта

### Структура кода

```
object_teleportation/
├── index.html          # Основной HTML файл с UI и логикой рендеринга
├── js/                 # JavaScript библиотеки
│   ├── three.min.js    # Three.js для 3D-графики
│   ├── OrbitControls.js # Управление камерой
│   └── dat.gui.min.js  # GUI для настройки параметров
├── wasm/               # Rust код для WebAssembly
│   ├── Cargo.toml      # Конфигурация Rust проекта
│   └── src/
│       └── lib.rs      # Основная логика физики и симуляции
└── wasm/pkg/           # Скомпилированные WASM файлы (генерируется)
```

### Компоненты

- **JavaScript (index.html)**:
  - UI и цикл рендеринга
  - Взаимодействие с WebAssembly
  - Управление Three.js сценой

- **Rust (wasm/src/lib.rs)**:
  - Создание и управление сеткой частиц
  - Физическая симуляция (пружины, демпфирование)
  - Логика телепортации через порталы
  - Интеграция метода Рунге-Кутты 4-го порядка

### Работа с изменениями

При внесении изменений в код:

1. **Изменения в Rust коде**:
   ```bash
   cd wasm
   wasm-pack build --target web
   ```
   Затем обновите страницу в браузере.

2. **Изменения в HTML/JavaScript**:
   - Просто обновите страницу в браузере
   - `miniserve` можно оставить запущенным

## 🎯 Особенности

### Физическая симуляция

- **Метод Рунге-Кутты 4-го порядка** — точное численное интегрирование
- **Пружинные связи** — между соседними и диагональными частицами
- **Демпфирование** — для стабильности симуляции
- **Автоматическое удаление пружин** — при превышении максимального расстояния

### Система порталов

- **Типы порталов**:
  - Тип 0: Отражение (reflection)
  - Тип 1: Перспектива (perspective)
  - Тип 2: Обычный портал (regular)

- **Телепортация**:
  - Определение пересечений с порталами
  - Трансформация позиций и направлений
  - Поддержка множественных проходов через порталы

### Визуализация

- **Режим отражений** — показ телепортированных версий объекта
- **Цветовое кодирование** — разные цвета для разных типов линий
- **Интерактивная камера** — масштабирование и перемещение
- **Отладочная сетка** — для визуализации координат
